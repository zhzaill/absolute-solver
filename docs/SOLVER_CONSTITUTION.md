# Absolute Solver 宪法

版本：3.1
日期：2026-11-06（Asia/Shanghai）

Absolute Solver 只做一件事：**把 Cortico 的能力投影到操作者自己的各种设备上。**

投影之后，设备上能看见并用到 Cortico——它的桌宠/对话界面、它的声音、它已接入的工作区和工具能力。Cortico 仍是唯一的大脑；设备本地同时跑 ASR、TTS、LLM，作为投影的底座。

## 唯一回路

```text
Cortico 决定投影什么
  → SSH 连到目标设备
  → 在设备上加载 Cortico 的页面和声音，调用设备本地 ASR / TTS / LLM
  → 拿回真实回执
  → 确认设备上看得见、听得到、用得上
```

投影是目的，SSH 是手段，本地 ASR/TTS/LLM 是底座。

## 三条底线

1. **投影的是 Cortico 的能力**，不造第二个大脑。
2. **每台设备本地同时跑 ASR/TTS/LLM。**
3. **回执必须真实**：设备上真的显示、播放、执行了，才算投影成功。

## 旧模型

旧的 Presence（存在位置）和「无门权限」不再是主线。SSH 是唯一的连接和授权层，权限就是账户权限。旧实现归档在 `archive/pre-ssh-2026-11-06` 分支，仅作参考。
