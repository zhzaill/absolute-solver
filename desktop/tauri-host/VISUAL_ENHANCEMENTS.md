# Tauri Host 视觉增强

## 已实现的优化

### 1. **进场动画与过渡**
- 全屏覆盖层使用 0.6 秒缓动进场动画
- Sigil 图标持续脉冲发光（3 秒周期）
- 能量环扩散效果（2 秒周期）
- 标题文字发光呼吸效果

### 2. **矩阵字符雨背景**
- 随机生成 10-25 个字符的列
- 包含数字、字母和日文片假名
- 每列独立的下落速度和延迟
- 每 3 秒刷新字符内容
- 不透明度 15% 保持可读性

### 3. **TTL 租约可视化**
- 进度条实时显示剩余时间百分比
- 青色到蓝色渐变填充
- 发光阴影效果
- 每秒更新倒计时文本

### 4. **字幕打字机效果**
- 底部半透明字幕区域
- 逐字打字动画
- 自动计算打字速度（30-80ms/字符）
- 显示 2 秒后自动隐藏

### 5. **权限徽章**
- 右上角显示当前授予的权限
- 绿色发光点表示已授予
- 灰色点表示未授予
- 半透明背景 + 模糊效果

### 6. **增强的撤销按钮**
- 红色边框 + 发光阴影
- Hover 时放大 5%
- 大写字母 + 字间距增加视觉强度

### 7. **扫描线动画**
- 全屏循环移动的扫描线
- 青色半透明横条
- 8 秒完整循环

## 使用示例

### 显示字幕
```javascript
// 在 Hub 通过 WebSocket 发送时触发
showSubtitle('正在分析环境数据...', 3000);
```

### 监听新消息类型
```javascript
// 在 receiveGrant 或其他消息处理中调用
if (message.type === 'say') {
  showSubtitle(message.text, 5000);
}
```

## 性能考虑

- 矩阵动画仅在覆盖层显示时运行
- 使用 CSS3 动画而非 JavaScript 逐帧
- TTL 更新每秒一次，避免频繁重绘
- 字幕区域默认隐藏，按需显示

## 未来扩展

- [ ] 实时语音波形可视化（需要音频流）
- [ ] AI 状态指示器（思考中/说话中/等待中）
- [ ] 摄像头权限激活时的视频流边框

- [ ] 更多字幕样式（警告/错误/成功）

### 技术债：
- 矩阵效果在超宽显示器上列数过多（考虑最大列数限制）
- 字幕区域固定高度，长文本可能溢出（需要滚动或多行）
- TTL 进度条在短租约（<10 秒）时更新可能不够平滑

## 兼容性

- 测试环境：Windows 11 + Tauri 2 + WebView2
- CSS 动画依赖现代浏览器特性
- 使用 UTF-8 编码显示日文字符
- 无外部依赖，纯 HTML/CSS/JS
